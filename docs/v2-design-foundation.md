# V2 design foundation

This note records the initial design foundation. The Stitch archive was a visual reference, not implementation code. Its four desktop/mobile Discover and Restaurant captures suggest a warm editorial restaurant guide with restrained product UI.

- Palette: cream paper, white and pale-beige surfaces, espresso text, cassis actions, herb-green status, and terracotta accent. The archive's color notes contain conflicting primary/secondary values, so the screen direction informed the initial token choices.
- Type: EB Garamond for editorial headings; Plus Jakarta Sans for navigation, controls, and body copy. Font files are self-hosted through Fontsource.
- Rhythm: a 4px-based spacing scale, generous page gutters, thin borders, small structural radii, and pill-shaped exceptions.
- Photography: large, prominent imagery with a dark lower scrim where text overlaps; final images were selected and optimized in later phases.
- Responsive intent: a capped, spacious desktop layout and a single-column mobile flow. Navigation and fixed mobile actions were deferred to later screen work.

This phase established only shared tokens and global defaults. Later phases completed Discover, Restaurant, navigation, product behavior, and final asset selection.

The initial font bundle includes only the Latin subset for French content; revisit subsets if V2 adds other languages.
